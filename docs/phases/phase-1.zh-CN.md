# 阶段 1 — 词法器与语法分析器

**当前阶段：** P1。

P1 把源代码文本转换为可观察的语法树。名字解析和类型检查属于 P2，本阶段
刻意不处理这些语义。

## P1 交付内容

- 单次扫描的手写词法器，覆盖 v0.1 的全部关键字、字面量、运算符、标点、
  单行注释和块注释。
- 经过范围检查的 64 位有符号十进制/十六进制整数，以及解码后的字符串转义；
  词法错误携带源码位置，并在安全时继续扫描。
- 密封 AST，覆盖声明、语句、表达式，以及 v0.1 文法中为后续阶段预留的指针
  和定长数组类型语法。
- 与优先级文法逐层对应的递归下降 Parser。赋值右结合，其余二元运算符左结合。
- 按语句边界恢复错误，一次输入可报告多条诊断。
- 输出稳定的缩进式 AST 打印器。
- `xlang tokens <file>` 与 `xlang parse <file>` 命令。

## 试运行

新建 `hello.xl`：

```xlang
fn main() -> int {
    let answer: int = 40 + 2;
    return answer;
}
```

执行：

```bash
./gradlew :xlang-cli:run --args="tokens hello.xl"
./gradlew :xlang-cli:run --args="parse hello.xl"
```

第一条命令显示 token 原文及源码位置；第二条打印 AST。若词法或语法分析产生
错误诊断，命令会以非零状态退出。

## 验证

```bash
./gradlew build
./gradlew phaseInfo
```

测试覆盖规范示例、注释、Unicode 与全部支持的转义、整数范围、表达式优先级、
后缀表达式、预留类型语法，以及在同一文件中从至少四条语法错误恢复。
