# 阶段 6 — 后端与 `.xo` 目标文件

**当前阶段：** P6。

P6 连通 P1–P3 构建的编译器和 P4–P5 构建的机器。一份合法 xlang 源文件现在会
依次经过词法分析、语法分析、类型检查、XIR 降级、机器码选择和可重定位目标文件生成。

## 后端策略

第一版后端刻意优先保证可观察性，而不是优化：

- 每个 XIR 局部变量和临时值获得一个 8 字节栈槽。
- `r6` 为帧指针，`r7` 为栈指针，`r0` 保存返回值。
- `r3`–`r5` 是后端短生命周期临时寄存器。
- 常量、复制、算术、比较、分支、调用、全局变量和字符串地址降级为 P4/P5 ISA。
- 布尔比较变为显式的 `cmp` 和条件跳转菱形结构。
- XIR 基本块边转化为可重定位的绝对跳转目标。

它生成的指令比寄存器分配器更多，但每个 XIR 值都有一个直观内存位置，便于 trace。

## 调用约定

调用方逆序压入参数并执行 `call`。被调用方：

1. 压入旧 `r6`；
2. 把 `r7` 复制到 `r6`；
3. 为栈槽预留帧空间；
4. 从 `r6 + 16 + 8*n` 把参数复制到局部栈槽。

返回时先把结果装入 `r0`，从 `r6` 恢复 `r7`，弹出旧帧指针，再由 `ret` 消耗
返回地址；调用方随后丢弃参数区。该约定无需四寄存器快速路径即可支持任意参数数量。

## XO01 目标文件格式

`.xo` 以大端 ASCII 魔数 `XO01` 开头，随后是段长度/数量和以下内容：

- `text`：带零占位符的 XMachine 编码指令；
- `data`：8 字节全局存储和以 null 结尾的 UTF-8 字符串；
- 符号：名称、段、偏移、大小及全局/局部可见性；
- 重定位：目标段/偏移、`ABS32` 或 `ABS64`、符号和 addend。

调用与跳转使用 `ABS32`，全局变量和字符串地址使用 `ABS64`。函数内部基本块边
也保留为重定位，因此 P7 可以自由拼接 text 段而不修改编译器输出格式。
`XObjectIO` 提供确定性的二进制读写，并拒绝损坏或截断的头部。

## 编译

```bash
./gradlew :xlang-cli:run --args="compile examples/hello.xl"
./gradlew :xlang-cli:run --args="compile examples/hello.xl -o /tmp/hello.xo"
```

不传 `-o` 时，目标文件写到源码旁并替换扩展名为 `.xo`。命令打印 text/data 大小
及符号/重定位数量。非法源码只输出原诊断，不生成残缺对象。

## 验证

```bash
./gradlew build
./gradlew phaseInfo
```

后端测试使用一个最小测试链接器应用重定位，再把结果放到 XMachine 运行。验收程序
包含循环、比较、分支、五参数调用和栈帧，最终返回 19。其它测试覆盖全局变量、
字符串、全部重定位类型、XO01 精确往返、非法输入门禁、输出路径及 CLI 产物可读性。
