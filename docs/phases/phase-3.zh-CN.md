# 阶段 3 — 三地址 XIR

**当前阶段：** P3。

P3 把 P2 的已定型语法树转换成一门小而显式的中间语言。AST 描述源码长什么样，
XIR 则描述后续机器阶段需要执行哪些原子操作，以及控制流如何连接。

## XIR 结构

- `Module` 持有全局声明和函数。
- 每个 `Function` 声明带类型的虚拟参数，以及有序的 `BasicBlock` 列表。
- 每个基本块由三地址指令组成，并以且仅以一条 `jump`、`branch`、`return`
  或 `unreachable` 终结。
- 值采用稳定前缀：全局变量为 `@name`，唯一命名的局部变量为 `%name.N`，
  编译器临时值为 `%tN`。

指令包括带类型常量、复制、一元运算、二元运算和函数调用。顶层初始化表达式
不会被隐藏或丢弃，而是保留在合成的 `$module_init` 函数中。

## 控制流降级

- `if` / `else` 变成 then、else 和汇合基本块。
- `while` 变成条件、循环体和出口基本块。
- `break` 跳到当前循环出口，`continue` 跳到循环条件。
- `&&` 和 `||` 会生成分支，确保右操作数真正短路，而不是被提前求值。
- 词法遮蔽的同名变量会获得不同的虚拟名称。

P3 只在完整 P2 流水线成功后运行。非法源码会输出原始源码位置诊断，不生成
残缺的 XIR 模块。

## 试运行

```bash
./gradlew :xlang-cli:run --args="ir examples/hello.xl"
```

输出是确定性的，并有意保留足够细节，便于在调试器中逐步观察或作为黄金测试数据。

## 验证

```bash
./gradlew build
./gradlew phaseInfo
```

测试覆盖算术表达式拆分、局部变量唯一命名、有/无返回值的调用、全局变量及模块
初始化、`if`、循环、break/continue、短路控制流、全部基本块终结、非法输入门禁
和 CLI 输出。
